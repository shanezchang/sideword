# Bundled runtime notices

These notices accompany the native Python runtime and its embedded dependencies.
They do not change Sideword's MIT license.

Source: https://github.com/astral-sh/python-build-standalone/tree/20260211
Files: LICENSE.<component>.txt, preserved verbatim.

Zstandard's BSD notice comes from https://github.com/facebook/zstd/blob/v1.5.7/LICENSE.

The build additionally copies the installed Python LICENSE.txt and PyInstaller's
COPYING.txt (which includes its bootloader distribution exception).
Review notices when upgrading the bundled runtime or changing its provenance.
