# Security / 安全报告

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/shanezchang/sideword/security/advisories/new).
Please include the release/version, macOS version, minimal reproduction and impact.
Do not attach personal word books, learning databases, tokens or account details.
For ordinary bugs, use [Issues](https://github.com/shanezchang/sideword/issues).
There is no guaranteed response time or long-term-support release policy yet.

请通过上方 GitHub 私密入口报告安全问题；附版本、系统和最小复现即可。
不要把词库、学习数据库或凭据发到公开 issue。普通问题仍用 Issues。

The Mac download is an **unnotarized preview** with an ad-hoc signature, not a
Developer ID signature. SHA-256 detects damaged downloads; it is not proof of
publisher identity. Download only from this repository's Releases. Never disable
Gatekeeper or remove quarantine attributes in bulk. See the
[installation guide](docs/install-macos.md) for supported installation and recovery.

Study data stays local. Website visit analytics are separate from terminal study;
see [the website privacy notes](site/README.md#website-analytics).
