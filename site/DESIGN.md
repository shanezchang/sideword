# Sideword website

A Decide/Learn page: understand the terminal learning loop, then install or inspect
the source. Not a browser learning service, dashboard or account system.

## Direction

Retain Sideword's green identity, improve its mark into two folded strokes forming
an S: a page turning and a return to a word. Use Manrope's open, rounded lowercase
for the wordmark instead of generic terminal monospace. The terminal itself retains
monospace; brand and product UI are intentionally distinct.

Palette: cloud #f7faf8, paper #ffffff, ink #163630, forest #14776b,
mist #e3f2ec, secondary ink #51665e. Dark mode reverses surface/ink, not semantics.
Self-host Manrope for Latin, PingFang/Noto Sans SC/system fallback for Chinese.
Only commands and the terminal demonstration use monospace.

Borrow Lusion's generous negative space and scale contrast, not its WebGL, fonts or
assets. Borrow the actual Sideword learning sequence, not a decorative code window.

Layout: left-aligned promise and install action beside a larger interactive word
preview; below it, the read/remember/review sequence, installation and compact FAQ.
Mobile stacks the same reading order. No made-up testimonials, counts or ratings.

Review before implementation: a centered hero and three identical feature cards
would say little about this product. Replace that plan with a working demonstration
and a review timeline; the mark is the only ornamental brand element.

## Behavior and boundaries

Two complete static pages, / and /zh/, with reciprocal language links and metadata.
No automatic locale redirection, login, backend or database. Production-only,
cookie-free aggregate website analytics respects DNT/GPC; no learning telemetry.
Demo state is session-only and does not claim to run the real scheduling engine.
Copy has success/failure feedback; no-JS still exposes the full install command.
No autoplay or decorative motion. Honor reduced motion and visible keyboard focus.
Current package limitations (30 original words, Apple Silicon, unnotarized preview)
must remain visible near installation.
