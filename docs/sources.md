# Provenance and scope

Sideword is an independent Python implementation, developed by Shane Chang with
AI coding assistance. No implementation code from the following reference apps
is copied or linked into this repository.

- [Vocage](https://github.com/proycon/vocage): reference for focused terminal recall.
- [Sotto](https://github.com/affromero/Sotto): reference for keyboard-first interaction.
- [不背单词](https://bbdc.cn/index): public contextual-learning and review principles;
  its proprietary algorithm is not reproduced. Sideword has its own simple schedule.

`src/sideword/data/sample.json` contains independently authored short Chinese explanations and
British IPA for 30 common words. `src/sideword/data/examples.json` contains AI-assisted original
practice sentences, translations and collocations. They are demonstration content,
not copied textbook excerpts, official IELTS questions or expert-certified lessons.
Both are covered by this repository's MIT license. Corrections are welcome.

The author's private prototype used local word lists from
[Qwerty Learner](https://github.com/RealKai42/qwerty-learner), whose repository is
GPL-3.0. Those files are not included in this public repository or its Git history.
Their third-party content rights were not cleared for this distribution. The code
supports local compatible JSON files, but does not download or relicense them.

Audio is generated by the user's macOS voices; no recordings or voice models are
distributed here. Linux audio is not implemented. Native Windows is not supported.
