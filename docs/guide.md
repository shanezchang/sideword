# 使用指南

## 启动与偏好

```sh
sideword                     # 默认英音自动播放
sideword --quiet             # 仅本次关闭自动播放，不覆盖保存的偏好
sideword --page-size 10       # 保存每页词数，支持任意正整数
sideword --book sample        # 打开指定词本
sideword --list-books         # 查看可用词本
sideword --version
```

源码运行时，在命令前加 `uv run`。`M` 也能修改每页词数：输入数字，Enter 保存，
Esc 取消。屏幕放不下一页时，随选中词滚动；分页数量不会偷偷改变。
建议 80×24，最低 42×15。`NO_COLOR=1 sideword` 使用单色。

## 学习页

| 按键 | 操作 |
| --- | --- |
| ↑↓ / K J | 多词页选词；单词详情滚动全文 |
| ←→ / H L | 多词页翻页；单词模式翻词 |
| Enter | 查看或关闭完整详情；复习时揭晓 |
| M | 输入每页词数 |
| 空格 / S | 读选中单词 / 英文例句 |
| A / V / - / X | 自动播放 / 英美音 / 慢速 / 停止 |
| 1 / 2 | 选中词还不熟 / 记住了 |
| F / T | 收藏 / 例句译文开关 |
| R / P / U | 到期复习 / 七天排程 / 不熟的词 |
| Tab / ? / Esc | 首页 / 帮助 / 保存退出 |

列表会裁短过长释义，Enter 可看全文。翻页只是浏览，不自动把整页记作学过。
按 2 后，词从日常列表移出，焦点转到下一词；收藏和查词仍可以找到它。
收藏、熟悉度和可选拼写成绩分开保存。

## 复习规则

第一次记住：1 天后复习。之后按时复习仍记得，间隔依次为 3、7、14、30、60 天，
最高保持 60 天。忘记则回到 10 分钟，并重新进入日常学习列表。
到期前重复按“记住”不会刷高阶段或推迟原日期。

复习始终逐词进行：先看英文回忆，再 Enter 揭晓，对照后按 1 / 2。启动时到期优先，
程序关闭时没有后台提醒。该规则是透明的简化间隔排程，不是记忆保留率预测。

## 本地数据

默认目录：`~/.local/share/sideword/`，遵循 `XDG_DATA_HOME`。

```text
sideword/
├── progress.sqlite3   学习、复习、收藏与配置
├── books/             自己导入的 JSON 词库
└── audio/             系统合成语音缓存
```

升级应用不会覆盖这些数据。备份前关闭程序，复制整个目录；不需要手工编辑数据库。
测试新设置可以隔离数据：`sideword --data-dir /tmp/sideword-demo`。

## 排错

- 无声音：确认使用 macOS 且有英语系统声音，运行 `sideword --audio-check`（会发声）。
- Linux：学习可用，发音后端尚未实现。Windows 原生终端不支持，可尝试 WSL。
- 词库错误：运行 `sideword --check`，错误包含词本名或行号；参照[词库格式](word-books.md)。
- 非交互终端：使用 `--check`、`--list-books` 或 `--stats`；TUI 需要真实终端。
- `--stats` 目前只输出可选拼写测验统计，词卡学习与复习排程在首页和 P 页面查看。

语音是系统合成，不是真人词典录音。缺例句或音标会明确标注，不会生成未经核对的解释。
